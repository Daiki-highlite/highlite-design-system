## 収益モデルを広げる

現行プランはすべてプロジェクト型（納品して終わり）。200万/月の安定には、**モデルそのものを広げる**必要があります。

### 収益モデルの選択肢

#### A. ブランドOS型リテイナー（月額顧問）

企業のブランド運営をAI × デザインで継続サポートする月額契約モデル。

- **内容**：ブランドガイドライン管理 / AI活用体制の維持・更新 / 月次チェックイン / 制作物レビュー
- **単価感**：30〜80万円/月
- **特徴**：解約されない限り毎月入る。3社で200万を超える

> 現行のClear/Prismは「構築フェーズ」。このモデルはその後の「維持フェーズ」として自然につながる。

#### B. スポット型ブランド監査（ブランドAI診断）

既存ブランドのAI活用状況・ブランド一貫性を診断するパッケージ。

- **内容**：ブランド現状評価 / AI活用ギャップ分析 / 改善ロードマップ提示
- **単価感**：50〜150万円
- **特徴**：意思決定前の企業が入りやすい。そのままClear/Prism/リテイナーへ転換できる

#### C. ホワイトラベル提供（代理店・コンサル向け）

大手エージェンシーやコンサルティング会社に、AI × デザインの実行力を裏側で提供する。

- **内容**：代理店の名前で案件を受けて、Highliteが実装する
- **単価感**：1案件50〜200万円（代理店マージン抜き後）
- **特徴**：営業コストゼロで案件が来る。ブランド露出はないが確実な収益になる

#### D. 法人向けAIブランディング研修・ワークショップ

社内でAI × ブランドを自走させるためのトレーニングプログラム。

- **内容**：半日〜1日ワークショップ / AIツール活用 / ブランドガイドライン実装演習
- **単価感**：50〜100万円/回
- **特徴**：単発でも高単価。現行Clearの入口にもなる

#### E. IPO・資金調達後の企業向けブランドパッケージ

調達直後・上場準備中の企業向けに、フルブランド構築からAI実装まで一括提供。

- **内容**：ブランド戦略 / VI刷新 / デザインシステム構築 / AIツール導入 / チームトレーニング
- **単価感**：500万〜2,000万円
- **特徴**：KPI②（2,000万案件）の本命ライン。上場前後・M&A後の企業は予算と緊急性がある

## KPI① 毎月200万円（7月〜）

### 7月に向けての現実解

6週間で「プロジェクト型だけで200万」は構造的に難しいため、**モデルの組み合わせ**で達成を狙う。

**推奨ポートフォリオ（月200万の内訳例）**

| 収益源 | 件数 | 単価 | 月収 |
|--------|------|------|------|
| ブランドOS型リテイナー | 2社 | 60万/月 | 120万 |
| Clear / Prismプロジェクト | 1件 | 80万/月換算 | 80万 |
| **合計** | | | **200万** |

リテイナー2社を6週間で確保するには、**今週から人脈への直接打診**が必要。

### アクション（優先順位順）

1. 今すぐ話せる経営者・意思決定者を10人リストアップ
2. LPではなく「その会社専用の1枚提案書」を持って打診
3. 「まず月30万の顧問から試す」という入口を作る（ハードルを下げる）
4. 1件でも取ったら、それを実績として次の打診に使う

## KPI② 2,000万円の大型案件

### 有望なシナリオ

#### シナリオ1：IPO・大型調達後の企業のフルリブランド

調達直後の企業は、予算・緊急性・社内承認の3つが揃っています。

- ターゲット：直近1〜2年でシリーズB以降を調達したSaaS・スタートアップ
- 内容：ブランド戦略 → VI → デザインシステム → AI実装 → チーム研修
- 単価：1,500万〜2,500万円

#### シナリオ2：M&A・事業統合後のブランド整合

複数ブランドの統合・新会社設立時に、ブランドの再定義が急務になります。

- ターゲット：統合発表〜1年以内の企業、PE系に買収されたブランド
- 内容：ブランドアーキテクチャ設計 → 統合VI → 社内展開ガイド → AIツール化
- 単価：1,000万〜3,000万円

#### シナリオ3：大手事業会社の新規事業ブランド立ち上げ

大企業の新規事業は社内承認を経た予算がある。動きは遅いが確実。

- ターゲット：大手メーカー・商社・金融の新規事業部門
- 内容：新ブランド定義 → サービスVI → デジタル実装 → AIオペレーション設計
- 単価：500万〜2,000万円

### タイムライン

```
6月：ターゲット企業5〜10社のリストを作り、接点を洗い出す
7〜8月：決裁者への直接打診 or 紹介経由でのアポ
9〜10月：提案・ネゴ
11〜12月：クローズ
```

## KPI③ マルジェラレベルの高感度ブランド案件

### 「マルジェラレベル」の定義を広げる

マルジェラ本体だけでなく、以下も同等に狙える。

| カテゴリ | 例 |
|----------|---|
| 欧州ラグジュアリー（日本法人） | Margiela, Loewe, Bottega Veneta |
| 日本のラグジュアリー・プレミアム | Issey Miyake, Undercover, Sacai, Fragment |
| ラグジュアリーホスピタリティ | Aman, The Peninsula, 星野リゾート |
| プレミアムプロダクト | B&O（Bang & Olufsen）, LEICA, HASSELBLAD |
| プレミアムビューティ | THREE, Shiseido Prestige Lines |

### 高感度ブランドへの参入ルール

このカテゴリにはコールドアプローチはほぼ機能しない。入るには以下の順番が必要。

```
① ポートフォリオに「高感度な仕事」を1件入れる
      ↓
② 業界の人・代理店と接点を持つ
      ↓
③ 紹介経由で商談に入る
```

### AIの打ち出し方に注意する

ラグジュアリーブランドは「AI製」「大量生成」を嫌います。  
ポジションは「AIを使っているが、判断・審美眼・ブランドへの理解は人間が担っている」。

- 打ち出す言葉：「ブランドの本質を守りながら、実装スピードを上げる」
- 避ける言葉：「AI自動生成」「コスト削減」「効率化」

### 今年中にできる現実的なアクション

1. ラグジュアリー・ファッション隣接の代理店・PRファームと接点を作る
2. 「高感度ブランドのAI活用をどう考えるか」という思考リーダーシップ記事をBrandriに出す
3. 業界イベント（Design Week Tokyo 等）に参加・出展を検討する
4. 接点がある人の紹介をたどる（2次・3次のつながりを掘る）
