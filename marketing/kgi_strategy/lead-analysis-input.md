## 2. なぜつながったのか — 5つの示唆

1. **品質が営業装置になっている** — Touchstarは納品物を見た第三者からの指名。アウトバウンドゼロでも「見せられる成果物」が次の案件を連れてくる。
2. **紹介は「人」ではなく「ハブ」から連鎖する** — 入江氏、メディカルフォース、ビューティードア（→ピックルボール→レタリー）。案件内で生まれた「個人のファン」がハブ化。
3. **相手にないケイパビリティが決め手** — スピー（動画）、アラウンド（Studio）、リアリス（PM）、ビューティードア（ブランディング）。「相手が内製できない機能」が最強の発注理由。
4. **役割の拡張・見立て直しが単価と継続を作る** — リアリスはデザイン→PM→組織支援へ拡張。P.I.E.E.は「マーケ依頼」をブランディングと見立て直しWS受注。入口の案件は広げられる。
5. **あらゆる人生レイヤーの縁が資産** — 前職・前々職・1社目・Sun*・学生時代・高校・親族まで全レイヤーから案件発生。**ただし補充されない資産なので、いずれ枯れる。**

## 3. 構造上の課題（5つ）

| # | 課題 | 内容 |
|---|---|---|
| 1 | **ハブ依存** | 入金ベースで最大ハブ（リアリス関連）が約4割。リアリスの月額はここ数ヶ月縮小傾向。ハブが細ると売上直撃 |
| 2 | **入口が「過去」にしかない** | リード起点はほぼ全て過去の職歴・友人・親族。新しい人脈・接点を生む活動がなく、資産を取り崩している状態 |
| 3 | **紹介の外からの導線ゼロ** | 事例公開・SNS・Web経由の案件は0件。「見て依頼」が起きているのに、見せる場所が納品先周辺にしかない |
| 4 | **小口単発の写真・動画** | Vol小案件は全て撮影系単発。紹介維持には有効だが、拡張しない限り工数対効果が低い |
| 5 | **獲得レバーが全て受動的** | 紹介を「待つ」構造。能動的に動かせる獲得手段（イベント・提携・営業装置）を会社として持っていない |

## 4. リード獲得アイデアマップ（提供価値起点・25案）

着手時期: 短＝0〜3ヶ月 / 中＝3〜12ヶ月 / 長＝1年〜

### A. 経営の言語化を入口に（上流WS）
- 短: ブランド健康診断 30分無料セッション＋診断シート
- 中: MVV策定90分体験WSの定期開催(低価格有料) / 商工会議所・経営者コミュニティへの出張WS
- 長: 第二創業（事業承継）ブランディングの型化 / MVVメソッドの冊子・書籍化

### B. 一気通貫パッケージ×提携チャネル
- 中: 開業ブランディング一式（内装・機器商社・税理士経由）/ 調達後スタートアップ向けブランド整備パック（VC提携）/ 採用ブランディングパック（人材会社提携）
- 長: 業界特化パッケージ＋業界セミナー（美容医療・介護・留学）

### C. デザイン×PMという希少性の外販
- 中: フラクショナルCDO/デザイン組織立ち上げ支援（月額）/ デザイン機能のない開発会社・SIerのパートナー営業 / 登壇・寄稿「デザイナーがPMをやる価値」
- 長: デザイン×PM講座（卒業生ネットワーク化）

### D. 撮影内製の差別化
- 短: 「本物のブランド撮影が標準で入るWeb制作」の打ち出し / 撮影単発からブランディングへのアップセル動線
- 中: 「撮影＋制作」セットパッケージの販売

### E. 品質を見せて獲得する（証明型）
- 短: ビフォーアフター事例ショーケース（冊子・展示）/ 納品披露ミニ内覧会の定例化
- 中: 「1日ブランドスプリント」公開イベント（デモ営業）
- 長: 事例展示・自主企画展の定期開催

### F. 紹介インフラ・コミュニティ
- 短: 紹介キット＋結果報告・お礼の運用 / 既存客への年間計画ヒアリング・近況レター
- 中: 非競合専門家（税理士・開発・内装・印刷）の相互送客網 / 代理店・コンサルのホワイトレーベル制作パートナー
- 長: 経営者×クリエイターの少人数コミュニティ主催

## 5. KGI 200万タスク（kgi-200man-tasks.html）への接続

この分析が既存タスクに与える影響:

- **t00（既存案件ヒアリング）→ ほぼ完了扱いにできる**: このスライド自体が t00 の成果物に相当。業種・規模・経路が整理済み
- **t03（ターゲットセグメント再定義）への直接入力**: 実績の重心は「美容医療・介護・留学・スタートアップ」＋「上流WS/ブランディング」。SaaS絞りからの変更先の有力候補
- **t02a（実績集）の緊急度が上がる**: 「紹介の外からの導線ゼロ」「見て依頼が起きているのに見せる場所がない」→ 実績集＋LP掲載は構造課題3への直接の処方箋
- **t17（事例記事化）の優先度 highest の裏付け**: 品質が営業装置になっている（示唆01）のに公開導線ゼロ
- **t24/t25/t26（能動アプローチ）の必然性**: 構造課題5「獲得レバーが全て受動的」への対応
- **t27（隣接専門家向け1枚資料）**: アイデアF「非競合専門家の相互送客網」と直結
- **新リスク認識**: リアリス関連が入金の約4割かつ縮小傾向 → リテイナー多角化（t08/t12/t16）は「成長」ではなく「防衛」の意味を持つ
