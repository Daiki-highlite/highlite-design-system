# 「GEO対策」狂騒曲 ― Googleは「特別な施策は不要」、Redditはスパム戦争、中小企業の勝ち筋は

*ソース: Search Engine Journal / EMARKETER / Search Engine Land / TechTimes / windowsforum.com / Google公式ブログ / jinrai.co.jp + Web横断調査(直近30日中心)*

## 結論サマリー(3行)

1. Google検索の「AIモード」は世界180以上の国・地域(日本含む)に展開され、月間利用者はローンチから約1年で10億人を突破。「10本の青いリンク」からの転換が数字でも裏付けられた一方、Google自身は2026年5月公表のガイドで「GEO/AEOは特別な新技術ではなく、従来のSEOの延長」と明言し、llms.txtや特殊なスキーマなどの"対策"を名指しで「不要」と否定した。
2. その裏でRedditは2026年7月、AIに"本物の口コミ"として引用させるためのスパム投稿を1日2.5万件検知・削除していると発表。GEO業者によるコミュニティ汚染が社会問題化し、5月には業者運営の関連subredditが2つ、通報キャンペーンでBANされた。
3. 「AIに引用されれば集客できる」は半分正解・半分誤解。ChatGPTは実際にリンクを踏ませるより3倍以上の頻度で"言及のみ"にとどめており、AI経由の実クリック流入はWeb全体のわずか1%程度という調査もある。中小企業の勝ち筋は小手先の対策ではなく、独自データと専門性そのものにある。

## 1. 「AIモード」はもう主流 ― 日本にも定着した検索の地殻変動

Googleは2025年9月9日にAIモードの日本語提供を開始して以来、この10か月で急速に定着させてきた。2026年7月時点の公式発表によれば、AIモードの月間利用者数はローンチから約1年で**10億人**を突破し、AI Overviews(検索結果に表示される要約)は**25億人**規模に達している。米国ではAIモードでの追質問(フォローアップ)が月40%超のペースで増加しており、検索は「キーワードを打つ」行為から「AIと対話する」行為へ移行しつつある。

この変化を追い風に、この1年で急速に膨らんだのが「GEO(Generative Engine Optimization)」「AEO(Answer Engine Optimization)」といった新語だ。EMARKETERの予測では、2026年に米国人口の**31.3%**が生成AI検索を利用する見込みで、SEO業界の調査でも従業員の**59%**が「GEO」という呼称を使うと回答するなど、業界用語としてすでに定着している。

## 2. Google自身が「特別な対策は不要」と自己否定

ところが2026年5月、Google自身が公開した新しいAI検索最適化ガイドが業界に波紋を広げた。Search Engine Journalの報道によれば、Googleは「生成AI検索向けの最適化は、結局のところ検索体験の最適化であり、依然としてSEOに他ならない」と明言。さらに踏み込んで、**llms.txt・コンテンツのチャンク分割・AI向けの special schema・AI向けの書き直し**といった、GEOコンサル業者が売り込む代表的な"対策"を名指しし、「Googleの生成AI機能には不要」と断言した。

皮肉なのは、この否定にもかかわらず、llms.txt採用サイトはGoogleの検索結果に安定して表示される数として2026年5月時点で約**12万件**(ピーク時は約20万件)にまで増えていること。「効果がない」と名指しされたテクニックが、なお業界内で拡散し続けている構図が浮き彫りになった。

## 3. Redditで起きている「GEOスパム戦争」

引用を勝ち取るための過熱は、コミュニティサイトそのものを揺るがし始めている。Reddit社は2026年7月6日、マーケターがChatGPTやGeminiなどの回答エンジンに"本物のユーザーの声"として認識させる目的で、Reddit上に偽の口コミ・体験談を大量に仕込んでいる実態を公表。同社の自社AIがこうした「GEOスパム」を**1日あたり約2万5,000件**検知しているという。

背景にあるのは、Redditが大規模言語モデルの回答で引用される最も頻度の高いドメインの一つであるという事実だ。ChatGPT Search・Perplexity・Google AIモードを横断した調査では、Redditは回答全体の**11.3%**で引用元として登場する。「AIに好意的に紹介してもらう近道」としてRedditが狙われた結果、2026年5月には業者が運営する関連subreddit(SEOforAI、LLMTrafficなど)が、r/SEOコミュニティ主導の通報キャンペーンによって2つ相次いでBANされる事態にまで発展した。

## 4. 「引用される」と「集客できる」の間にある大きなギャップ

ここまでの過熱ぶりを見ると「AIに引用されれば売上に直結する」と思いがちだが、現実はもっと地味だ。Search Engine Landが670万セッションを分析した調査では、ChatGPTはブランドを**リンク付きで引用する頻度より、名前だけ言及する頻度の方が3倍以上多い**(1回答あたり言及2.37回に対し実引用0.73回)ことが分かっている。さらに別の調査(tryanalyze.ai)では、AI経由の実クリック流入は**Web全体のトラフィックのわずか1%程度**にとどまるとの推計も出ている。

つまり「AIの回答に社名やサービス名が出てくること」と「実際にサイトへ人が来ること」の間には大きな断絶がある。GEO業者の営業トークが煽る「引用数◯倍」という数字だけを追いかけると、実態の伴わない投資になりかねない。

## 5. それでも中小企業にこそ勝ち筋がある

一方で悲観する必要もない。jinrai.co.jpが紹介するGEO対策の成功事例では、月間のAI引用数が**5件から45件(約9倍)**に伸びた企業もあり、こうした成果は3〜6か月で表れるケースが多いという。重要なのは、AIが引用するのは「情報量が多いサイト」ではなく「その分野で一次情報・独自データを持つサイト」だという点だ。大手メディアが網羅しきれない専門領域では、むしろ中小企業の方が引用されやすい構造がある。

Googleが名指しで否定したのは「小手先のマークアップやファイル追加で引用が増える」という幻想であって、「専門性の高い一次情報を、結論から明確に書く」という王道は否定されていない。GEO対策とは結局、質の高いコンテンツ制作という本質に回帰する話だ。

## Highliteへの示唆

1. **「GEOツール」ではなく「一次情報コンテンツ」を売る** ― llms.txt設置や特殊タグ付けといった小手先商材は、Google自身が「不要」と名指しした領域。Highliteが提案すべきは「専門性の高い一次情報・独自データを結論から書く」という王道のコンテンツ設計であり、これは既存のWeb制作力・AIデザイン支援とそのまま接続できる。
2. **自社のt29(robots.txt)課題の優先度が再確認された** ― OPERATIONS.mdに記録済みの通り、brandri.jp / highlite.co.jpは全クローラーを拒否する設定のままで、AI検索エンジンにも一切引用されない状態にある。今回のリサーチで「AIモードは日本でも月間利用が主流化している」ことが裏付けられた以上、この是正は軸1(記事公開)の資産価値だけでなく、顧客への提案力にも直結する自社課題として最優先で解消すべきだ。
3. **顧客への期待値設定こそ差別化になる** ― 「AIに引用されれば集客爆増」という単純化した営業トークは、実際のクリック流入がごくわずかという実態と乖離する。「引用はブランド想起・信頼構築への中長期投資であり、即効の集客効果は限定的」という誠実な説明ができることが、GEOブームに乗じた粗悪なコンサル業者との差別化ポイントになる。
