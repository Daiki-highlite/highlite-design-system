# Brandri 記事ライター（経営者トラック）

**デザイナートラックとは設計思想が根本的に違う。** 混同しないこと。
デザイナー向けを書くときは `brandri-writer-designer.md` を使う。

書いた記事は Brandri（brandri.jp）の Articles / 経営者トラックとして公開される。
本ファイルは Brandri側の `SPEC_KEYWORD_ARTICLES.md` に準拠している。
**Brandri側の規範が更新された場合はそちらが正。**

参照必須：
- `marketing/branding_seo_keywords_50.md`（キーワード一覧）
- `skills/_shared/company-profile.md`
- `skills/_shared/track-record.md`
- `skills/_shared/brandri-strategy.md`

## 最重要原則（これを外したら書き直し）

### 1. タイトルと前半に「ブランディング」を出さない

見出しは**経営者の痛み語だけ**で書く。
「ブランディング」という語は、**03章で初めて出す。**

```
title / lead / 01章 / 02章  → ブランディング不使用
03章                        → ここで初めて「それをブランディングと呼ぶ」と翻訳
```

これは記事の骨格そのもの。守らないと経営者トラックとして成立しない。

### 2. 痛みが先、思想は後

経営者の実語彙（値決め・粗利・応募が来ない・属人化・相見積もり）で捕まえてから、
Brandriの思想語（判断の一貫性・見た目の手前・選ばれる理由）で格を上げる。

順番を逆にしない。最初から思想語で書くと、経営者は自分の話だと思わない。

### 3. ゴールでなく仕組みを語る

- ✗「有名になる」 → ○「相見積もりに呼ばれなくなる構造」
- ✗「イメージアップ」 → ○「値決めの根拠」

### 4. 煽らない

「〜すべき」の乱発より、「分かれ目」「論点」の提示を優先する。

## 記事ハーネス

**分量：1,800〜2,400字**（lead＋本文）。デザイナートラック（2,000〜2,600字）より短い。

| 章 | 役割 | 字数 |
|---|---|---|
| `title` | 痛み語だけの見出し。問い・対比・言い切りの形 | 1行 |
| `lead` | **経営者の独白から始める。**「ブランディング」不使用 | 80〜120字 |
| `sections[0]` 01 症状 | 痛みの言語化。読者が「うちのことだ」と思う場面描写。数字や定型句（相見積もり・紹介料）で解像度を上げる | 400〜500字 |
| `sections[1]` 02 構造 | なぜ起きるのか。根性論・価格論ではなく「選ばれ方の構造」の問題であることを、**まだブランディングと言わずに**解剖する | 450〜550字 |
| `sections[2]` 03 解の名前 | **ここで初めて翻訳する**——「それを整える営みを、ブランディングと呼ぶ」。Brandriの思想語へ接続 | 450〜550字 |
| `sections[3]` 04 明日の一歩 | 実務の初手（社内で聞く・書き出す・棚卸す）＋内部導線 | 350〜450字 |
| `pullquote` | 立場を一文で（02の後に自動挿入される） | 1文 |
| `takeaways` | 経営が判断すべきこと | 2〜4項目・各40字前後 |

各章は3段落程度。1段落140〜170字が目安。
「短く言い切る」文体だと1段落100字前後になりがちで、そのままだと字数に届かない。

## 禁止語（使ったら書き直し）

**捨てる言葉：**
世界観／トンマナ／クリエイティブ／アートディレクション／パーパス／ナラティブ／
エンゲージメント／バズる／認知度アップ／フォロワー／映え／おしゃれ・かっこいい・素敵／
デザイン思考／DX／イノベーション

**注意：** これらはデザイナートラックでは**解禁**されている語。
経営者トラックでは厳禁。トラックを間違えないこと。

**その他：**
- 「リブランディング」は**見出し禁止**（本文では「作り直す」「定義し直す」）
- 「MVV」は用語ページへのリンク文脈のみ可
- 「CACの高騰」等のマーケ語を使わない
- **英字の全大文字は禁止**（Highlite / Brandri のようにタイトルケース。頭字語 AI・M&A・IPO 等のみ例外）

## 推奨語彙

**経営者の実語彙（01・02章で使う）**
値決め／粗利／利幅／相見積もり／値引き／指名／価格転嫁／安売り／
応募が来ない／内定辞退／定着／採用単価／紹介料／属人化／事業承継／看板／暖簾／
無形資産／与信／信用

**Brandriの思想語（03・04章で使う）**
判断の一貫性／見た目の手前／選ばれる理由／比較される前に決まっている状態／
想起の資産化／指名の構造

## sources と内部導線

### sources（必須）

事実の創作は禁止。実在が確認できない固有名詞・数値・引用は書かない。
引用（稲盛和夫・松下幸之助等）は出典を sources に明記する。不確かなら一般論に留める。

外部一次情報を持たない記事では、Highlite編集部の自己出典形式を使う：
```json
{ "key": "highlite-<slug>", "title": "「<検索語>」をめぐる編集ノート",
  "author": "Highlite 編集部", "year": 2026, "type": "編" }
```

### 内部導線（各記事2〜3本必須）

`related` に以下から2〜3本を選ぶ：
- 診断（`index.html#diagnostic`）
- 5大疑問（`basics/what-is-brand` `basics/does-it-work` `basics/where-to-start`）
- 状況ページ（`situations/build` `situations/grow` `situations/renew`）
- 入口詳細（`entries/issue-*` `entries/phase-*` `entries/term-*`）

デザイナートラックは3本必須だが、**経営者トラックは2〜3本**でよい。

## キーワード記事の書き方

`marketing/branding_seo_keywords_50.md` のキーワードを1語＝1記事で消化する。

### 進め方

早川さんの推奨順に従う：
1. **Tier 1 の「インナーブランディング」「リブランディング」クラスタ**から着手
   （準ビッグ×競合低×子記事が揃っており、親子構造で早期に面が取れる）
2. 次に急伸中の「ブランディング 会社」「採用ブランディング」「webブランディング」「広報ブランディング」
3. Tier 4 の業種特化で商談導線

### 記事化の手順

1. キーワードを1つ選ぶ
2. **そのキーワードで検索する経営者の痛みは何か**を特定する
   （例：「ブランディング 会社」→ どこに頼むか決めきれない・失敗したくない）
3. その痛み語をタイトルに据える（キーワードそのものをタイトルにしない場合もある）
4. 4章構成で書く。03章で初めてブランディングへ翻訳
5. `slug` はキーワードの英語表記（例：`inner-branding`）

### 既存記事との重複を避ける

Brandriには既に経営者記事が68本ある（num 190〜264）。
同じ論点を繰り返さない。重複しそうなら角度を変えるか、既存記事に内部リンクする。

## 文体ルール

**やること**
- 短く言い切る
- 段落は意図を持って切る
- 具体的な数字・固有名詞・実際に起きたことを書く
- 主張には必ず根拠をつける

**やらないこと**
- 対比構造の反復（「〜ではない。〜だ」の連打）
- 詩的な締め
- 説明過多
- 「いかがでしたか」「まとめると」等の定型句
- 煽りタイトル（「〜の落とし穴」「危険な〜」）

## 著作権・引用の上限

- 直接引用は1記事1箇所・50字以内まで。引用符を外しても同じ
- 元記事の要約は記事全体の1〜2割まで
- 元記事の構成をなぞらない
- 事実・数値を借りるときは出典を明記する
